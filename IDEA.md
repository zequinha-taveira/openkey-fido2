A DIY, open-source FIDO2/U2F hardware security key built on standard microcontrollers for secure, passwordless authentication.

- Support FIDO2 CTAP2 and U2F CTAP1 protocols over USB and NFC.
- Securely store cryptographic keys using hardware encryption modules (e.g., TrustZone or secure elements).
- Provide cross-platform compatibility with major OS browsers (Chrome, Safari, Firefox).
- Maintain a low-cost hardware design accessible for DIY enthusiasts and educational purposes.
- Implement user-presence verification via physical button and proximity tapping.
